# Project Falcon — Spec Notes

Project Falcon is the client tax-automation tool. The internal demo deadline is October 2, 2026, and the staging review happens in Room 4B the week before.

The stack is deliberately boring: SQLite for local storage and ONNX Runtime for the document-classification model. No server component in v1.

Budget is capped at 18,000 USD for the year, mostly contractor hours. Dana wants weekly burndown updates posted in the team channel every Friday.
